# Fatboy-coder

*An independent technology practice focused on products, systems and protocols.*

Building useful software. Extracting reusable systems from recurring engineering problems.

Projects and experiments are developed independently and through **13DevLab**.

## Selected work

### Products

**[OneClickPDF](https://oneclickpdf.app/)**  
A multilingual PDF conversion product focused on fast, low-friction document workflows.

### Protocols

**[Portable Persistent Goal Protocol (PPGP)](https://github.com/Fatboy-coder/ppgp)**  
A vendor-neutral continuity protocol for long-running coding agents, with an installable Agent Skill, public specification and citation metadata.

### Experiments

**Statecraft Zero**  
A private political simulation exploring persistent world state, institutions and emergent player-driven systems.

## Operating loop

```text
IDEA
  ↓
EXPERIMENT
  ↓
PRODUCT
  ↓
REAL-WORLD PROBLEMS
  ↓
PATTERNS
  ↓
PROTOCOL
  ↓
BETTER PRODUCTS
```

Products create problems. Problems reveal patterns. Patterns that generalize can become protocols. Protocols improve the next product.
